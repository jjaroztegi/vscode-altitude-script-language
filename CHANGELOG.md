## [0.1.0] - 2026-03-07

### Added
- First standalone release of the VS Code extension.
- Programmatic TypeScript-based language runtime.
- Context-aware completion for sections, controls, properties, events, nodes, variables, cursors, built-ins, and system variables.
- Diagnostics for unresolved references, duplicate declarations, control-property validation, and brace issues.
- Hover, go to definition, and document outline support.
- Full-document formatter with indentation fallback setting.
- Settings for formatter indentation and diagnostics toggles.
- Embedded SQL highlighting support.
- ASL snippets for controls and common UI patterns.
